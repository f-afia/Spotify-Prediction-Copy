
# Overview
This project explores the problem of predicting song popularity on Spotify using a combination of audio features, musical metadata, and external social media engagement data. Multiple machine learning approaches are evaluated, including regression and classification models, to assess how well different feature sets capture the factors that contribute to song popularity.


## Dataset Sources				
### Spotify Audio Features Dataset
Source: Kaggle
Contains audio descriptors (e.g., danceability, energy, tempo) and metadata for over 100,000 Spotify tracks.
## YouTube Music Hits Dataset
### Source: Hugging Face Datasets (akbargherbal/youtube-music-hits)
Provides engagement metrics such as YouTube view counts for popular music tracks.
